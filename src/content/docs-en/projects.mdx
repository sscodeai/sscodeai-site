## keysmith

An MCP server and CLI for AI-agent-safe secret management, designed to keep plaintext secrets out of agent context.

- Repository: [`sscodeai/keysmith`](https://github.com/sscodeai/keysmith)
- Docs: [keysmith](/keysmith/)
- Architecture: [keysmith Architecture](/keysmith/architecture/)
- Runtime: Go single static binary
- Security model: age encrypted store, masked views, handle-passing, self-healing rotation, Vault short-TTL credentials
