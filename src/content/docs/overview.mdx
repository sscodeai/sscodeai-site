# SSCodeAI

SSCodeAI は、日本の IT 開発、SIer、受託開発、自社サービス、SaaS、EC、製造業 DX で使える AI coding workflow と agent library を整理するサイトです。

## Projects

### superpowers-ja

AI coding agent に計画、TDD、systematic debugging、code review、完了前検証、日本語の開発現場向け workflow を追加します。

- Claude Code / Cursor / Codex CLI / Gemini CLI / OpenCode などに対応
- 日本語 code review、障害報告、受入テスト仕様、Git 運用を補強
- `npx superpowers-ja` で project に install
- upstream / 中文版との違いは [superpowers 系 version の違い](/superpowers-ja/version-differences/) に整理

### agency-agents-ja

日本の現場で使いやすい AI 専門家 agent と workflow の library です。

- **394 agents** (⭐ 115 japan-original + 279 upstream-aligned adapted to Japan) + **27 workflows**
- 要件定義、設計、QA、障害対応、PM、GIS / 地図・空間データ、healthcare、公共 sector、research、platform engineering、document generation、China network、accessibility、payments、i18n、API platform、FinOps、search relevance、sales、support、legal、finance などを収録
- `security/` division で AppSec、cloud security、incident response、SecOps、threat intelligence をカバー
- `gis/` division で自治体 DX、防災、インフラ保全、PLATEAU、BIM/CIM、ドローン測量、Web GIS をカバー
- Backlog / Redmine / Jira、GitHub / GitLab / Bitbucket、kintone、LINE WORKS、Sansan、freee を想定
- 個人情報保護法 / インボイス制度 / 電帳法 / 適時開示 / TDnet、製造業 DX、公共 sector の compliance を考慮
- 上流 [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents) (MIT) を fork し、日本市場向け原創 115 件 + 上流由来 279 件（日本市場向けに adapted）で構成
- `npx agency-agents-ja install` で Claude Code / GitHub Copilot / Antigravity / Gemini CLI / OpenCode / OpenClaw / Cursor / Aider / Windsurf / Qwen Code / ZCode / Kimi Code / Codex / Osaurus / Hermes / Mistral Vibe に導入可能
- `superpowers-ja` の `workflow-runner` と組み合わせて複数 role workflow を実行

### img2threejs

参照画像に写ったオブジェクトを、メッシュ抽出や外部アートパックではなく、TypeScript と Three.js の手続き型コードとして再構築する skill です。

- 1 枚の画像から `ObjectSculptSpec` を作成し、段階的な build pass で `THREE.Group` factory を生成
- blockout、構造、形状、マテリアル、表面ディテール、ライティング、インタラクション、最適化の順に品質ゲートを通過
- レンダーと参照画像を比較し、視覚レビューで次のパスに進むか自己修正するかを判断
- Sony WF-1000XM3、Gerber knife、Doraemon house などの [demo gallery](/img2threejs/demos/) を掲載

### keysmith

AI agent が secret value を直接 context に入れずに扱えるようにする MCP server + CLI です。

- age encrypted store、masked views、handle-passing で secret の平文露出を避ける
- `keysmith scan --rotate` で git 履歴上の漏えい検出と rotation を補助
- stdio、HTTP/SSE、Streamable HTTP transport に対応
- [keysmith](/keysmith/) に install、MCP 設定、CLI、security model を整理

### Proctor

AI agent の recorded trajectory を採点し、失敗した step と root cause を説明する Agent Eval / LLMOps tool です。

- tool correctness、loop detection、task completion、plan quality / adherence などを評価
- earliest-deviation backtracking で failing step を特定
- evidence chain と root-cause classification で agent failure を説明
- [Proctor](/proctor/) に quick start、dataset format、CI gate、architecture を整理

### takumi

検証可能な agentic software delivery のための model-agnostic orchestration platform です。

- 単一の coding agent ではなく、runtime、workflow、quality gate、artifact、traceability、independent verification を統合
- fake / Pi / DeepSeek / CLI bridge runtime adapter、Japanese SI / V-model workflow、MEA loop を提供
- held-out verifier tests を持つ Agent Eval framework で false completion を検出
- [takumi](/takumi/) に quick start、architecture、core ideas、roadmap を整理

### aiitg

信頼できない文書が LLM に届く前に、隠された prompt injection を検出し、サニタイズし、信頼ラベルを付け、policy を適用する zero-trust input security layer です。

- 6 形式（`docx` / `xlsx` / `xls` / `pdf` / `html` / `pptx`）× 7 detector で座標レベルの証拠を出力
- `aiitg sanitize` / `aiitg trust` / `aiitg policy` で strip・redact、safe/caution/dangerous ラベル、allow/quarantine/human_approval/block を適用
- MCP server（`aiitg-mcp`）と Claude Code `PreToolUse` hook で agent からも利用
- [aiitg](/aiitg/) に pipeline、CLI、設計原則を整理

### ai-skill-maker

ラフな意図、リポジトリの証拠、反復ワークフローから、再利用可能な AI skill と instruction bundle を生成する meta-skill です。

- functional / document / workflow / project maintainer skill と、`AGENTS.md`・`CLAUDE.md`・Cursor・Copilot 向け adapter bundle を生成
- evidence labels、Trust Gate、release gate、9,000-token ceiling の file budget、protected core principles の fingerprint lock
- Node.js 18+ の scripts のみで動作
- [ai-skill-maker](/ai-skill-maker/) に renderer、workflow、安全モデルを整理

### ai-project-skill-maker

AI coding agent 向けに、長く使えるプロジェクト保守用 skill と instruction bundle を生成する meta-skill です。

- genesis mode（新規プロジェクト）と repo mode（既存リポジトリ）の 2 mode
- `observed_fact` / `declared_intent` / `recommended_standard` / `inferred_assumption` の evidence model
- refresh 時に保持される `BEGIN USER RULES` ブロック
- [ai-project-skill-maker](/ai-project-skill-maker/) に生成物、scripts、adapter を整理

### skills-ja-JP

Matt Pocock Agent Skills（`sscodeai/skills`）の日本語ローカライズ版で、日本語で agent と会話する際の意図の取り違えを減らします。

- Engineering 15 + Productivity 5 の **20 skills** を収録
- `npx skills@latest add sscodeai/skills-ja-JP` で install
- ディレクトリ名、skill name、コマンド、パス、URL、identifiers を保持する翻訳方針
- [skills-ja-JP](/skills-ja-jp/) に skill 一覧と翻訳・検証手順を整理

### decision-workbench

意思決定者の認知を「決める前」に広げる 6 段階の tool です。winner は選びません。

- bias flag → 5 stance の独立 divergence → cross-exam → option map → constraints → human decision
- hidden gold option set に対する eval は single model 26% → naive multi-agent 78% → decision-workbench 100%（12 問中 12 問）
- mock mode は API key 不要（Python + FastAPI / React）
- [decision-workbench](/decision-workbench/) に pipeline、API、eval を整理

### decision-space-expansion

`decision-workbench` から抽出した、Agent Skills 形式の 3 段階 decision methodology です。

- Diverge（異種 model committee）→ Structure（consensus / true divergence / pseudo-divergence）→ Converge（制約を戻し、人間が決める）
- コードも依存も不要な単一 `SKILL.md` で配布
- Claude Code、Cursor / Windsurf、Codex、Gemini CLI などに導入可能
- [decision-space-expansion](/decision-space-expansion/) に loop、pitfalls、install 先を整理

### eli5

任意のトピックを、大きな SVG 図と最小限のテキストで説明する picture-first explainer generator です。

- 各 step は大きな inline SVG + 1 行 caption、3〜4 問の quiz、interactive glossary を同梱
- 出力は外部リクエストゼロの単一 HTML（offline-safe）
- `scripts/export.sh` で PDF / PNG に export
- [eli5](/eli5/) に同梱物、使い方、設計思想を整理

### fusion-cache

exact → semantic → prefix-cache accounting を 1 つの middleware に統合した、LLM API 向け caching layer です。

- L1 exact（canonicalized SHA-256 key）、L2 semantic（embedding + cosine）、L3 prefix accounting の 3 layer
- benchmark は 97% hit rate、P95 0.7 ms、P50 3.2 s → 0.1 ms
- OpenAI 互換 gateway（`fusion-cache serve`）、MCP server（`fusion-cache-mcp`）、Redis store を同梱
- [fusion-cache](/fusion-cache/) に layer、benchmark、gateway を整理
