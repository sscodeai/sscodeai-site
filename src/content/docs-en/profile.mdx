# Profile

SSCodeAI is an open-source project that organizes AI coding workflows, agent libraries, and hands-on tutorials for Japanese IT development teams.

The main focus is moving AI agents from "a convenient assistant" to "a repeatable, explainable working procedure". Requirements, design, implementation, review, testing, incident response, and operational handover — deliverables and checkpoints are adapted to Japanese development culture.

## Focus Areas

| Area | What SSCodeAI publishes |
| --- | --- |
| AI coding workflow | planning, TDD, debugging, code review, verification, pre-release checks |
| Japanese localization | prompts / skills aligned with Japanese development culture, acceptance, audit trails, incident reporting, handover |
| Agent library | specialist roles for requirements, design, QA, PM, support, finance, legal, sales, and more |
| Documentation | install guides, tutorials, version differences, quality management, release notes |
| Open source maintenance | upstream tracking, explicit documentation of Japan-market diffs, generated docs sync |

## Projects

- [superpowers-ja](/superpowers-ja/quickstart/) — a Japanese AI coding skill pack for Claude Code, Cursor, Codex CLI, Gemini CLI, and more.
- [agency-agents-ja](/agency-agents-ja/) — an AI specialist agent library adapted for Japanese IT development, SIer, custom development, SaaS, EC, manufacturing DX, and public sector.
- [SSCodeAI site](/overview/) — the documentation site that gathers docs, blog, tutorials, and generated catalogs.

## Working Style

SSCodeAI's documents prioritize practical shareability.

- Readable in Japanese, with English technical terms alongside where helpful
- Record not only artifacts but also assumptions, rationale, and verification steps
- Separate upstream-derived content from Japan-market originals / adaptations
- No personal, customer, contract, or internal-spec information in public documents
