## agency-agents-ja

日本の IT 開発、SIer、受託開発、自社サービス、SaaS、製造業 DX、公共 sector で使える AI 専門家 agent library です。

- **394 agents** (⭐ 115 japan-original + 279 upstream-aligned adapted to Japan) + **27 workflows**
- Latest release: **v0.4.0** (2026-08-13); latest upstream sync docs: **2026-09-12**
- Upstream: [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents) (MIT)
- Repository: `sscodeai/agency-agents-ja`
- Install: `npx agency-agents-ja install`
- Supported tools: Claude Code, GitHub Copilot, Antigravity, Gemini CLI, OpenCode, OpenClaw, Cursor, Aider, Windsurf, Qwen Code, ZCode, Kimi Code, Codex, Osaurus, Hermes, Mistral Vibe
- Main docs: [agency-agents-ja Overview](/agency-agents-ja/)

- Repository: [`sscodeai/img2threejs`](https://github.com/sscodeai/img2threejs)
- Manual: [img2threejs Manual](/img2threejs/)
- Demos: [img2threejs Demo Gallery](/img2threejs/demos/)
- Runtime: Three.js + TypeScript factory

- Output: `ObjectSculptSpec` JSON + `THREE.Group` factory + review comparison sheets

## local-agent-toolkit

Agent の memory、skill 管理、実行 trace を local-first に扱う toolkit です。`agency-agents-ja` のような agent library や `superpowers-ja` のような skill pack を、必要な単位で配布・導入する周辺 tooling として追跡します。

- Repository: [`jnMetaCode/local-agent-toolkit`](https://github.com/jnMetaCode/local-agent-toolkit)
- Components: `engram` (memory), `skillet` (skill manager), `tracelet` (run tracing)
