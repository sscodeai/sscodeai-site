## img2threejs

An image-to-3D skill that reconstructs the object in a reference image as code-only procedural Three.js models.

- Repository: [`sscodeai/img2threejs`](https://github.com/sscodeai/img2threejs)
- Manual: [img2threejs Manual](/img2threejs/)
- Demos: [img2threejs Demo Gallery](/img2threejs/demos/)
- Runtime: Three.js + TypeScript factory
- Output: `ObjectSculptSpec` JSON + `THREE.Group` factory + review comparison sheets
