## Projects

### superpowers-ja

AI coding agent に planning、TDD、debugging、review、verification、日本語開発現場向け workflow を追加します。

### agency-agents-ja

日本の IT 開発、SIer、受託開発、自社サービス、SaaS、EC、製造業 DX、GIS / 地図・空間データ、公共 sector で使える AI 専門家 agent library。
**374 agents** (⭐ 114 japan-original + 260 upstream-aligned adapted to Japan) + **27 workflows** を収録。

### img2threejs

1 枚の参照画像から、コードだけで構成された手続き型 Three.js モデルを再構築する skill です。
品質ゲート、段階的なビルドパス、レンダー比較レビューにより、アニメーションに使いやすい `THREE.Group` factory を生成します。
