# agency-agents-ja

`agency-agents-ja` is an AI specialist agent library for Japanese IT development, SIer, custom development, in-house services, SaaS, EC, manufacturing DX, GIS / spatial data, healthcare, and public sector.

- **Repository**: [sscodeai/agency-agents-ja](https://github.com/sscodeai/agency-agents-ja)

- **Install**: `npx agency-agents-ja install`
- **License**: MIT

## Two kinds of agents

### ⭐ Japan-market originals (115)

Agents designed independently for the Japanese market — production-ready and not present in the upstream English library.

- **SIer / custom development / multi-tier subcontracting** workflow agents
- **kintone / LINE WORKS / Sansan / freee** integration specialists
- **Personal-information protection / invoicing / electronic bookkeeping / timely disclosure / TDnet** compliance agents
- **Manufacturing DX / public sector / security operations** specialists
- **Learning-plan** agents for certifications and languages (TOEIC, Eiken, IELTS / TOEFL, JLPT, DELF / DALF, etc.)

### Upstream-aligned, adapted to Japan (273)

Agents mapping 1:1 to the upstream `msitarzewski/agency-agents` inventory, keeping an `upstream_path:` link to the original file.

Currently `translation_status: adapted` — not a literal translation, but rewritten for the Japanese market while preserving role-level intent (description, role, expected scenarios, and required checks are all adapted to Japanese practice).
