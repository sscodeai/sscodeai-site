## decision-workbench

A six-stage tool that expands the decision-maker's cognition before they decide: it diverges options, reveals blind spots, structures the map, and hands the decision back to a human. It never picks a winner.

- Repository: [`sscodeai/decision-workbench`](https://github.com/sscodeai/decision-workbench)
- Docs: [decision-workbench](/decision-workbench/)
- Runtime: Python (FastAPI) + React (mock mode needs no API keys)
- Eval: against a hidden gold option set, single model 26% → naive multi-agent 78% → decision-workbench 100% (12 of 12)
- Tests: 25 tests (`uv run pytest`)
- License: MIT

## decision-space-expansion

A three-stage decision methodology distilled from `decision-workbench`: widen the option space with a heterogeneous model committee, structure the divergence, fold constraints back in, and let a human decide.

- Repository: [`sscodeai/decision-space-expansion`](https://github.com/sscodeai/decision-space-expansion)
- Docs: [decision-space-expansion](/decision-space-expansion/)
- Form: a `SKILL.md` in the Agent Skills format (no code, no dependencies)
- Loop: Diverge → Structure → Converge (with a mandatory human gate)
- Install: Claude Code, Cursor / Windsurf, Codex, Gemini CLI, or any Markdown-reading agent
- License: MIT

## fusion-cache

A framework-agnostic LLM API caching layer that fuses exact, semantic, and prefix-cache accounting into one drop-in middleware.

- Repository: [`sscodeai/fusion-cache`](https://github.com/sscodeai/fusion-cache)
- Docs: [fusion-cache](/fusion-cache/)
- Runtime: Python ≥ 3.10
- Layers: L1 exact (canonicalized SHA-256 key), L2 semantic (embedding + cosine), L3 prefix accounting (DeepSeek ~31× discount)
- Benchmark: 97% hit rate, P95 0.7 ms, P50 3.2 s → 0.1 ms
- Extra: OpenAI-compatible gateway (`fusion-cache serve`), MCP server (`fusion-cache-mcp`), Redis store
- License: Apache-2.0
