# superpowers-ja

`superpowers-ja` adds planning, TDD, systematic debugging, code review, pre-completion verification, and Japanese development workflows to AI coding agents.

- **Repository**: [sscodeai/superpowers-ja](https://github.com/sscodeai/superpowers-ja)
- **Install**: `npx superpowers-ja install`
- **Supported tools**: Claude Code, Cursor, Codex CLI, Gemini CLI, OpenCode

## What it adds

- **Japanese code review**, incident reporting, and acceptance-test specification workflows
- **Git operations** and delivery conventions for Japanese teams
- Audit scripts and eval transcripts to verify release quality
- Clear documentation of differences from upstream and the Chinese edition
